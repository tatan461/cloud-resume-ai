Cloud Resume Challenge with AI Assistant

2026

Problem: Most junior cloud portfolios show isolated demos instead of one coherent system spanning frontend, backend, IaC, CI/CD, and AI.

What I built: A personal resume site hosted on S3 and CloudFront with a serverless visit counter using Lambda, DynamoDB, and API Gateway. Kubernetes Cluster on Amazon EKS with Autoscaling & Observability

2026

What I built: A containerized application deployed to Amazon EKS with Terraform, Horizontal Pod Autoscaling, Helm, Prometheus, and Grafana. Images are pushed to Amazon ECR through GitHub Actions with automated tests and vulnerability scanning before deployment.

Stack: Docker, Amazon EKS, Kubernetes, Helm, Amazon ECR, Prometheus, Grafana, GitHub Actions, Terraform

AWS Cost Optimization Dashboard

2026

Problem: Cloud spend grows silently without visibility into idle resources or rightsizing opportunities.
